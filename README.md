# SortWise_WasteClassification

AI-Powered Waste Classification System for Household Recycling Support. ♻️

----------------------------------------
## Dataset
Two sets of data were merged : Total images= 5,054

TrashNet - 2,527 images 
+
Garbage Classification - 2,527 images 

ِِِِAcross 6 classes (Glass, Paper, Cardboard, Plastic, Metal, Trash).

----------------------------------------
## Model
MobileNetV2 with Transfer Learning. Test Accuracy: 95%.
